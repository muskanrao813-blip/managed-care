# Render Deployment Guide — Managed Care Dashboard

## What Gets Deployed

A live Managed Care dashboard that displays real data from daily pipeline scripts:
- **Dashboard**: HTML interface on port 8001
- **Data source**: CSV files generated by daily scripts (01-04)
- **Features**: Programme Analytics + Care Operations (No AI tabs)
- **Auto-refresh**: Reload button to refresh from latest CSVs

## One-Time Setup (10 min)

### 1. Create Render Account
Go to [render.com](https://render.com), sign up, and connect GitHub.

### 2. Create Web Service from GitHub
1. Dashboard → New → Web Service
2. Search for: `muskanrao813-blip/managed-care`
3. Select the repo
4. Name: `managed-care-dashboard`
5. Runtime: **Docker** (uses our Dockerfile)
6. Region: Singapore (or closest to you)
7. Branch: `main`
8. Click **Deploy** (Render auto-detects Dockerfile)

### 3. Set Trino Environment Variables
In Render dashboard → Environment → Add Variables:
```
TRINO_HOST=your-trino-cluster-host
TRINO_PORT=443
TRINO_USERNAME=your-trino-username
TRINO_PASSWORD=your-trino-password
TRINO_CATALOG=iceberg
TRINO_SCHEMA=managed_care
```

### 4. Wait for Deployment
- Build time: ~3-5 minutes
- Once "Live", public URL appears: `https://managed-care-dashboard-xxxx.onrender.com`
- Open URL → Dashboard loads with "Loading CSV data…"

## How It Works

**Daily Data Flow**:
1. Your machine: Scripts 01-04 run at scheduled time → Generate CSVs in `Data/` folder
2. Render: Dashboard server reads those CSVs
3. Browser: Displays live data from CSVs (refresh to see latest)

**Scripts that feed the dashboard**:
- `01_raw_data_program_allocation.py` → program_allocation.csv
- `02_comparison_retest_analysis.py` → comparison.csv
- `03b_device_eligibility_2026.py` → device_eligibility.csv
- `04_claude_analysis.py` → insights/recommendations

## Dashboard Sections

✅ **Programme Analytics**
- Overview: Camp reports, enrolled users, improvement rates
- Programme Outcomes: Condition-wise improvement (MC vs non-MC)
- Cohort Analysis: Risk stratification (Very High/High/Moderate)
- Year-on-Year: Improvement trends across years

✅ **Care Operations**
- Devices & Lifestyle: CGM, Glucometer, Weighing Machine, BP Monitor allocation
- Appointments: Booking rates, completion, zero-appointment users
- Engagement Activities: WhatsApp, voice, app nudge tracking
- Recommendations: AI-generated care suggestions

## Accessing the Dashboard

**Public URL**: Share this with stakeholders
```
https://managed-care-dashboard-xxxx.onrender.com
```

- No login needed
- Auto-refreshes CSVs every 30 seconds
- Manual refresh: Click "↻ Reload Data" button

## Local Testing (Before Render)

To test locally before deploying:
```bash
cd "Manage care python"
python run_dashboard.py
# Opens http://localhost:8001
```

Make sure CSVs exist in `Data/` folder (run scripts 01-04 first).

## Monitoring

Check Render dashboard for:
- ✅ Service status: "Live" = online
- 📊 Logs: Watch for CSV loading messages
- 🔴 Health: If goes down, check env vars (Trino access)

## Troubleshooting

**Dashboard shows "Error connecting"**:
- Check Trino credentials in Render environment variables
- Verify `Data/` folder exists and has CSVs

**No data appears**:
- Run scripts 01-04 locally to generate CSVs
- CSVs need to be in `Manage care python/Data/` folder
- Dashboard auto-discovers them

**Want to update dashboard**:
- Edit `managed_care_dashboard_final.html` locally
- Commit and push to GitHub
- Render auto-redeploys in ~2 min
